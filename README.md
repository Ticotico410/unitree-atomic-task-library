# Unitree Atomic Task Library

Unitree G1-D and R1-A7-D tabletop atomic task library covering 12 environments, 20 manipulation task families, and 200 atomic tasks.

Live site: https://unitree-atomic-task-library.smokyocean8.chatgpt.site

## Structure

- `dist/`: static website source and assets
- `.openai/hosting.json`: ChatGPT Sites hosting configuration

Open `dist/index.html` to preview the static site locally.
